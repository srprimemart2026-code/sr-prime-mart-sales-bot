# S.R. PRIME MART - Friendly Sales Bot
এই বটটি কাস্টমারের লাইভ মেসেজ পড়ে তাদের সাথে একদম বন্ধুভাবাপন্ন আচরণ করবে এবং বুদ্ধিমত্তার সাথে কনভেন্স করে পণ্য বিক্রি করাতে সাহায্য করবে।

### চালানোর নিয়ম:
1. প্রজেক্টের ফোল্ডারে টার্মিনাল ওপেন করে কমান্ড দিন: `npm install`
2. এরপর কমান্ড দিন: `node bot.js`
3. ব্রাউজার ওপেন হলে লগইন করে চ্যাট অন রাখুন।
