# S.R. PRIME MART - AI Auto-Reply Bot

Facebook Marketplace এবং Page ইনবক্সের কাস্টমারদের লাইভ মেসেজ পড়ে **Gemini AI**-এর মাধ্যমে স্বয়ংক্রিয়ভাবে উত্তর দেওয়ার Chrome Extension।

## ইনস্টল করার নিয়ম:
1. এই রিপোজিটরি থেকে কোডগুলো **Download ZIP** করে Extract করুন।
2. Chrome ব্রাউজারে `chrome://extensions/` ওপেন করুন।
3. উপরের ডানদিকে **Developer mode** চালু করুন।
4. **Load unpacked** বাটনে ক্লিক করে ফোল্ডারটি সিলেক্ট করুন।
5. এক্সটেনশন আইকনে ক্লিক করে আপনার **Gemini API Key** ও পণ্যের তথ্য দিয়ে সেভ করুন।
